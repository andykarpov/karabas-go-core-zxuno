# ZX-Uno core for Karabas Go / Mini / Mini G

ZX Spectrum core based on the ZX-Uno Spectrum core EXP28 ([zxtres/zxspectrum](https://github.com/zxtres/zxspectrum), GPL-3, (c) ZXUNO association, Miguel Angel Rodriguez Jodar and contributors), ported to the Karabas boards (Xilinx Spartan-6 XC6SLX25).
