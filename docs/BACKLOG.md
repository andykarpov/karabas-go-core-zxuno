# Бэклог ядра ZX-Uno

- **BIOS ZX-Uno в ядре** (пользователь, 2026-11-18): адаптировать BIOS ZX-Uno (zxdos/zxuno `firmware/firmware.asm`, GPL) и встроить в ядро. Какие параметры можно будет менять в BIOS (а какие остаются в OSD) — обсудить с пользователем отдельно, до начала работы. Сейчас BIOS нет: ПЗУ грузит прошивка (`roms` в `core.json`), заглушка ZX-Uno только пишет MASTERCONF; от BIOS взят лишь логотип (`logo256x192.rcs.zx7b`).
- **Меню 128K вместе с esxDOS** (пользователь, 2026-11-18): esxDOS 0.8.9 при старте включает 48K ПЗУ, поэтому при DivMMC On стартует 48K BASIC, а меню 128K видно только при DivMMC Off (пункт OSD). Варианты на потом: (2) патченое для esxDOS 128K ПЗУ вместо `128en.rom` (найти в наборах ПЗУ ZX-Uno, проверить); (3) оба: OSD DivMMC + патченое ПЗУ отдельным FL-пунктом.
